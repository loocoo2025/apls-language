- [ ] 需求明确并编号

- [ ] 架构/详细设计已更新

- [ ] 回归测试 PASS
- [ ] 静态分析无未处理严重问题
- [ ] 要求的 ASan/UBSan/TSan PASS
- [ ] 未删除/弱化正确测试
- [ ] 无未说明 workaround
- [ ] 无未说明行为变化
- [ ] 需求追溯已更新
- [ ] 如涉及正式需求 Baseline 或追溯关系变更，Node Coverage + Edge Consistency 机械校验 PASS，或例外已正式批准

- [ ] 已知遗留问题已登记
