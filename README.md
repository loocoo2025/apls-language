# APLS

APLS 是一门面向 AI Agent 的声明式软件系统规格语言，以及围绕它构建的编译器式工具链。

当前阶段：`REQUIREMENTS`。首要目标是拒绝歧义：合法输入只有一个规范化解释；无法唯一解释的输入必须被工具链拒绝，不能交给 AI 猜测。
